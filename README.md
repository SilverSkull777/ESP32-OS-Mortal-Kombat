# ESP32-OS-Mortal-Kombat
Here is the system overview, apps, games, and Mortal Kombat details in under 350 characters:Arduino OS is an ESP32 system with an OLED display. Apps include a calculator, clock, Wi-Fi manager, and AI tools. Games feature Snake, Dino, Breakout, Flappy Bird, and Mortal Kombat with 10 fighters, specials, and difficulties. Totally not written by an AI.
