# ESP32-OS-Mortal-Kombat
Here is a quick overview of the system, its apps, games, and a detailed look at Mortal Kombat:The System: Arduino OS is a minimalist multitasking operating system running on an ESP32 microcontroller with a 128x64 OLED display, analog joystick, and physical buttons.   Applications: Includes a full calculator, advanced clock/stopwatch/alarm system, Wi-Fi manager with captive network scanning, an AI assistant query tool, a numeric encoder/decoder, and hardware diagnostics for buttons and joysticks.   Games: Features a retro arcade collection including Snake, Dino Run, Breakout, Flappy Bird, and Mortal Kombat.   Mortal Kombat Details: A fully-featured portable fighting game featuring 10 selectable characters (like Scorpion, Sub-Zero, and Raiden), custom vector sprite animations, health and special attack meters, projectile and freeze mechanics, a dynamic difficulty selector ranging from Easy to Tryhard, and round-winning "Finish Him" sequences.
